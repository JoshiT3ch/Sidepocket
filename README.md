# Sidepocket

A static pickleball website prototype with a customizable 2D pixel player, demo rating, and downloadable story card.

## Open locally

Open `dist/index.html` in a browser. No build or installation is required.

## Files

- `dist/index.html`: website screens
- `dist/styles.css`: responsive styles
- `dist/app.js`: customization, demo ratings, browser storage, and PNG export

Ratings and match results are demonstrations. This prototype stores profile data in the current browser and has no server or player accounts.
